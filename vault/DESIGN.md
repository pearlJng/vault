# 가구 랜딩페이지 디자인 가이드

레퍼런스: [eladiodieste.com](https://www.eladiodieste.com/)(레이아웃/인터랙션 참고), 콘텐츠는 건축이 아닌 **가구 스튜디오 VAULT**로 전환.
컨셉: 하중을 견디는 짜임처럼, 화면도 최소한의 요소로 최대한의 무게를 견딘다. 검정은 밤의 작업대이고, 브라운은 그 위에 놓이는 원목 재료다. 색은 두 개뿐이지만 명도 단계로 위계를 만든다.

> 히어로 섹션의 `VAULT` / `LIFESTYLE` 워드마크와 `© 2026 · SEOUL` 마크는 브랜드 로고 취급으로 콘텐츠 전환 대상에서 제외한다. 그 외 About/History/Showcase/Contact 본문은 전부 가구(원목·짜임·구조) 언어로 쓴다.

---

## 1. 컬러 시스템

순수한 무채색 대신 따뜻한 검정을 기본으로 쓰고, 벽돌 브라운을 유일한 악센트로 절제해서 배치한다. 강조는 항상 한 곳, 나머지는 조용하게.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#0B0908` | 기본 배경 (Ground) |
| `--bg-elevated` | `#17120F` | 카드/패널 배경 (Surface) |
| `--bg-elevated-2` | `#1F1813` | 한 단계 더 밝은 표면 |
| `--line` | `#2C231C` | 테두리, 구분선 |
| `--line-soft` | `#201A15` | 옅은 구분선 |
| `--brick` | `#A8522B` | 주 악센트 (Brick) — 버튼, 강조 테두리, 포인트 |
| `--brick-deep` | `#6B3018` | 어두운 브라운 — 보더, 보조 강조 |
| `--brick-soft` | `#D99A6C` | 밝은 브라운 — 링크, 작은 텍스트 악센트(대비 확보용) |
| `--ink` | `#EFE7DB` | 기본 텍스트 (따뜻한 아이보리) |
| `--ink-muted` | `#9C8F83` | 보조 텍스트 |
| `--ink-faint` | `#6B6058` | 캡션, 라벨, 메타 정보 |

**원칙**
- 작은 텍스트/링크에는 `--brick`이 아닌 `--brick-soft`를 사용해 대비를 확보한다.
- 섹션별로 배경을 `--bg` ↔ `--bg-elevated` 사이에서만 오간다. 완전한 흰색/순색은 쓰지 않는다.
- 철학 섹션처럼 전환의 쉼표가 필요한 곳은 배경을 한 단계 더 낮춰(`--bg`) 텍스트만 밝힌다.

## 2. 타이포그래피

전 서체 고딕(산세리프)으로 통일. 세리프는 사용하지 않는다. 위계는 서체가 아니라 **굵기**로 만든다 — 헤드라인은 굵은 고딕, 본문은 레귤러 고딕, 수치·라벨·연도는 모노스페이스로 도면 주석처럼 처리한다.

| 역할 | font-family | Weight | Size | 비고 |
|---|---|---|---|---|
| Display (Hero) | `"Pretendard", "Apple SD Gothic Neo", "Noto Sans KR", -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` | 700 | ~152px (clamp) | letter-spacing −0.02em, `text-wrap: balance` |
| Display (Section H2) | 동일 | 700 | 26–36px | |
| Body | `-apple-system, BlinkMacSystemFont, "Segoe UI", "Pretendard", "Noto Sans KR", sans-serif` | 400 | 15px | line-height 1.75, 한 줄 최대 66자 |
| Label / Data | `"SF Mono", "JetBrains Mono", Menlo, "Noto Sans Mono", monospace` | 400 | 11px | letter-spacing 0.08–0.14em, uppercase |

**원칙**
- 강조가 필요한 단어만 `--ink`로 밝히고 나머지는 `--ink-muted`.
- 연도, 섹션 번호, 캡션은 항상 모노스페이스 + 대문자로 "도면 주석" 톤을 유지한다.

## 3. 사이트 구조 (4섹션, 단일 페이지 · 하위페이지 없음)

랜딩페이지 하나로 완결되므로 상단 메뉴는 전부 페이지 내부 앵커(`#hero` `#about` `#history` `#contact`)로만 이동한다. 실제 `<button>`은 문의 폼의 **'문의하기' 하나만** 존재 — 하위페이지가 없는 만큼 흐름을 방해하는 보조 CTA를 두지 않는다.

1. **히어로 (`#hero`)** — 화면을 꽉 채운 브랜드 워드마크. `VAULT`(상단) / 가로 구분선 / `LIFESTYLE`(하단)만 세로로 넉넉히 배치하고 카피 문단은 두지 않는다 — 철학은 소개 섹션에서 풀어낸다.
2. **소개 (`#about`)** — 상단 큰 서술문(재료가 스스로 구조가 되는 원칙)과 우측 정렬된 보조 문장, 하단 재료·구조·디테일 3분할 이미지 밴드로 브랜드를 설명. 각 이미지에 캡션이 오버레이된다.
3. **연혁 (`#history`)** — 프로젝트 히스토리를 하나로 소개. 이미지(텍스처 패널)와 연도·타이틀 텍스트가 좌우로 엇갈리며 겹쳐지는 구성.
4. **쇼케이스 (`#showcase`)** — 연혁과 컨택트 사이, `.wrap`을 벗어나는 풀블리드 와이드 이미지(2.14:1) 한 장으로 리듬을 끊는 구간. 우하단에 캡션 칩.
5. **컨택트 (`#contact`)** — 연락처 정보 + 문의 폼. 유일한 버튼인 '문의하기'로 마무리.

## 4. 레이아웃 & 인터랙션 원칙 — 이미지·텍스트 교차·레이어링

레퍼런스: [eladiodieste.com](https://www.eladiodieste.com/) Figma 재구성본(`node-id=2-2`). 실제 인물 사진 대신 브랜드 톤의 CSS 벽돌 텍스처(`.texture`)를 이미지 자리에 사용해 동일한 교차 구도를 재현했다.

| 항목 | 규칙 |
|---|---|
| Hero | 화면 꽉 채운 풀블리드 이미지(`img/hero.jpg`) 위에 워드마크 두 줄(`VAULT` 왼쪽에서 슬라이드인 / `LIFESTYLE` 오른쪽에서 슬라이드인)만 놓인다. `VAULT`의 `V`는 로고와 동일하게 `--brick-soft`로 강조. 카피 문단은 없음(`node-id=4-870`, `node-id=5-872` 참고). `prefers-reduced-motion` 시 애니메이션 생략. 히어로 텍스트(워드마크, `© 2026 · SEOUL`)는 브랜드 로고로 취급해 콘텐츠 언어 전환(건축→가구) 대상에서 제외한다. |
| Texture | `.texture`는 반복 벽돌 패턴 대신 단일 라디얼 그라디언트(`--brick` → `--brick-deep` → 거의 검정)로 단순화 — 히어로·소개·연혁의 모든 이미지 자리에 공통 적용. |
| About 교차 | 큰 서술문 아래 보조 문장을 우측 정렬로 크게 띄우고, 하단은 재료·구조·디테일 3분할 이미지 밴드에 캡션을 오버레이한다(`node-id=3-816` 참고). 3분할 이미지는 스크롤 진입 시 좌→우 순서로 위에서 아래로 열리는 커튼 리빌(`clip-path`, 0.9s, 각 0.18s 스태거)이 재생된다. 기본 딤 오버레이는 `rgba(11,9,8,.74)`로 짙게 유지되고(호버 시에만 0으로 사라짐). |
| History 레이아웃 | 세로 중심축 라인(`.history-track::before`, 50%) 기준으로 이미지가 좌/중앙/우를 넘나드는 캐스케이드 배치(`node-id=1080-3680` 최종 스펙). 연도 숫자는 항상 행의 정중앙(50%)에 고정. 캡션(`h-caption`: 타이틀·설명, 상태 뱃지는 삭제됨)은 각 이미지와 동일한 width/margin-left를 공유해 이미지 바로 아래 16px 지점에 정렬되며, 정렬 방향은 이미지 위치를 따른다 — 좌측 이미지는 `align-left`, 우측 이미지는 `align-right`, 중심축을 가로지르는 이미지는 `align-center`. 마지막 2024 항목은 이미지가 오른쪽 124px 거터를 뚫고 화면 끝까지 브레이크아웃한다. 모든 텍스트에 `word-break: keep-all`로 의미 단위가 깨지는 줄바꿈을 막는다. |
| History 스크롤 인터랙션 | 다이아몬드 마커는 `position: fixed; top/left: 50%`로 **뷰포트 정중앙에 고정**되고, 회전(구르는 효과)과 opacity만 스크롤에 따라 바뀐다 — 실제 이동은 콘텐츠가 마커를 지나쳐 스크롤되는 것으로 표현되므로 화면 전체를 쓸고 다니지 않는다. 중심축 라인은 회색 베이스(`::before`) 위에 아이보리톤(`--ink`) `.axis-fill`이 겹쳐지며, 그 높이가 "뷰포트 중앙이 트랙 안에서 얼마나 내려왔는지"에 정확히 비례해 자란다(회색→활성 전환). 마커도 `--ink`(다이아몬드 마커·axis-fill 모두 브릭 계열에서 화이트 계열로 변경 — 주황이 히스토리 섹션 톤과 이질적이라는 피드백). 연도 숫자(`work-year`)는 기본 회색(`--ink-faint`)이다가 화면 중앙선이 그 항목을 지나는 순간 `--ink`(아이보리)로 전환되고, 이미지(`work-figure`)는 동시에 `clip-path: inset(0 0 100% 0)→inset(0 0 0% 0)`로 **위에서 아래로 열리는 커튼 리빌**을 재생한다(0.5s, eladiodieste.com 참고). 트리거 지점은 이미지 정중앙이 아니라 **이미지 상단 - 140px(`REVEAL_LEAD`)** — 화면 중앙선이 실제로 이미지에 도달하기 전에 미리 열리기 시작해서, 마커가 지나갈 때는 이미 다 열려 있도록 리드타임을 준다. 상태는 **양방향**이다 — 아래로 스크롤해 화면 중앙선을 지나면 활성화(열림)되고, 다시 위로 스크롤해 중앙선이 그 트리거 지점보다 위로 올라가면 즉시 비활성화(위로 닫힘)된다. 화면 중앙선이 이미지 **하단**까지 완전히 지나가면(`is-passed`) 이미지 위에 `rgba(11,9,8,.45)` 오버레이가 0.7s에 걸쳐 서서히 덮여 살짝 딤 처리된다 — "지금 보는 항목"과 "이미 지나간 항목"을 시각적으로 구분한다. 이 상태도 위로 스크롤하면 되돌아간다. 마커는 진행률 4% 이전/96% 이후로 페이드 인·아웃하며 트랙 밖에서는 보이지 않는다. 마커 `z-index:0` < `.h-item` `z-index:1`이라 이미지·캡션 뒤로 흘러간다. 위치 계산은 `requestAnimationFrame`으로 스로틀링하고 트랙/이미지 좌표는 로드·리사이즈 시 한 번만 측정·캐싱한다. `prefers-reduced-motion` 시 마커를 숨기고 라인·연도·이미지를 즉시 활성 상태로 표시한다. 760px 이하에서는 중심축·마커·필을 숨기고 단일 컬럼으로 스택(리빌 애니메이션은 유지). |

| Nav | `position: fixed` 투명 헤더가 히어로 이미지 위에 겹쳐진다. 좌우 여백은 히어로 워드마크와 동일하게 124px(900px 이하 56px, 720px 이하 20px)로 정렬 — `.wrap`의 1040px 중앙 정렬을 쓰지 않고 전폭 패딩을 직접 준다. 스크롤 40px 이후 `.is-scrolled`가 붙어 어두운 반투명 배경 + 블러가 생긴다. 메뉴 라벨은 `INTRO / HISTORY / CONTACT` 영문 대문자, hover 시 밑줄 없이 텍스트가 위로 스크롤되며 같은 라벨이 아래에서 올라오는 롤 애니메이션(0.4s). 전부 페이지 내 앵커 이동(하위페이지 없음), `scroll-margin-top`으로 고정 헤더에 가려지지 않게 처리. |
| 섹션 eyebrow | About의 `INTRO`는 `.section-head`에 속하지 않는 독립 `<p class="eyebrow">`로 `.wrap` 전체 폭 기준 좌측 정렬. History의 `HISTORY`는 `.section-head` 안으로 들어가 타이틀·서브타이틀과 함께 **중앙 정렬**된다. Contact의 `CONTACT`는 독립 eyebrow(좌측 정렬)이고 그 아래 `.section-head`에 `.align-left`를 추가해 타이틀·서브텍스트까지 좌측 정렬한다. Contact 폼의 `.submit-row`는 `justify-content: flex-end`로 제출 버튼을 우측 정렬한다. |
| Responsive | 760px 이하에서는 교차 배치를 해제하고 이미지 → 연도 → 설명 순으로 단일 컬럼 스택. 히어로 크로핑도 비율을 낮춰 가독성 우선. |
